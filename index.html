사전준비Node.js 설치 확인 (필수!)
▼
왜 Node.js가 필요한가?
이유클로드 코드 자체가 Node.js 기반으로 만들어진 프로그램이에요. Node.js가 없으면 설치 자체가 안 돼요.
버전Node.js 18 이상이 필요해요. 낮은 버전이면 오류가 나요.
현재 버전 확인
$node --version
v20.0.0 처럼 나오면 정상. v18 미만이면 nodejs.org에서 새 버전 설치
$npm --version
Node.js 설치하면 npm은 자동으로 같이 설치돼요!
설치클로드 코드 설치 · 업데이트 · 제거
▼
npm install -g 란?
-gglobal(전역)의 줄임말. 내 컴퓨터 어디서나 claude 명령어를 쓸 수 있게 설치해줘요.
@@anthropic-ai/claude-code 는 패키지 이름이에요. npm 저장소에서 자동으로 내려받아요.
처음 설치 (최초 1회)
$npm install -g @anthropic-ai/claude-code
최신 버전으로 업데이트
$npm update -g @anthropic-ai/claude-code
새 기능이 추가되거나 버그가 고쳐지면 업데이트하면 돼요.
설치된 버전 확인
$claude --version
완전 제거 (삭제)
$npm uninstall -g @anthropic-ai/claude-code
실행클로드 코드 실행 방법 전체
▼
기본 실행 — 대화형 모드
$claude
대화형 모드란?
의미클로드가 계속 켜져 있고, 내가 질문하면 바로 답해주는 채팅 방식이에요. 일반적으로 가장 많이 쓰는 방식.
특정 파일을 열면서 시작
$claude 파일명.py
클로드가 시작하면서 그 파일을 자동으로 읽어둬요. "이 파일 어때?" 바로 물어볼 수 있어요.
질문 하나만 하고 바로 종료 (비대화형)
$claude -p "이 코드 분석해줘"
-p 옵션이란?
의미--print 의 줄임. 대화 창 없이 질문 하나 던지고 답 받고 바로 종료해요. 자동화 스크립트에서 많이 써요.
파일 내용을 입력으로 넘기기
$cat 파일명.py | claude -p "설명해줘"
cat 으로 파일을 읽어서 | (파이프)로 클로드에 전달해요. 파일을 직접 첨부하지 않아도 돼요.
작업 폴더 지정하면서 시작
$claude --cwd /경로/폴더명

$mkdir 폴더이름
$mkdir -p 상위/중간/하위 ← 중간 폴더도 자동 생성

pipPython 패키지 관리 (pip) 완전 정리
▼
pip 이란?
정의Python Package Installer. 파이썬에서 쓸 수 있는 외부 라이브러리(패키지)를 인터넷에서 자동으로 내려받아 설치해줘요.
예시pandas (데이터 분석), requests (웹 요청), openpyxl (엑셀) 등을 pip으로 설치해요.
$pip install 패키지이름
$pip install pandas requests openpyxl ← 여러 개
$pip install -r requirements.txt ← 목록 파일로 한번에
$pip install --upgrade 패키지이름 ← 업데이트
$pip uninstall 패키지이름
$pip list ← 설치된 패키지 전체
$pip show 패키지이름 ← 특정 패키지 상세 정보
$pip freeze > requirements.txt ← 현재 패키지 목록 저장
pip freeze > requirements.txt 하면 나중에 pip install -r requirements.txt 로 한방에 재설치 가능!
venv가상환경 (venv) — 왜 써야 하나?
▼
가상환경이 왜 필요한가?
문제프로젝트 A는 pandas 1.0, 프로젝트 B는 pandas 2.0이 필요할 때 — 둘을 같이 쓰면 충돌나요.
해결프로젝트마다 독립된 파이썬 환경(가상환경)을 만들면 각각 다른 버전을 쓸 수 있어요.
비유가상환경 = 각 프로젝트만을 위한 전용 방. 다른 방 물건이 섞이지 않아요.
① 가상환경 만들기 (최초 1회)
$python -m venv venv
프로젝트 폴더 안에 'venv'라는 폴더가 생겨요. 이 안에 독립된 파이썬이 들어있어요.
② 가상환경 켜기 (매번 작업 시작할 때)
$venv\Scripts\activate ← 윈도우
$source venv/bin/activate ← 맥/리눅스
켜지면 터미널 앞에 (venv) 표시! 이 상태에서 pip install 해야 가상환경에 설치돼요.
③ 가상환경 끄기
$deactivate
venv/ 폴더는 .gitignore에 추가해서 깃허브에 올리지 마세요! 용량이 엄청 커요.

▼
-p "프롬프트"  또는  --print "프롬프트"

언제: 자동화 스크립트에서, 파이프라인에서, 테스트할 때

claude -m claude-haiku-4-5
--cwd "경로"

claude --cwd /Users/나/프로젝트
--auto-approve
파일 수정/명령 실행 시 확인 없이 자동으로 허용
언제: 자동화 스크립트, 반복 작업, 신뢰하는 환경에서
claude -p "코드 정리해줘" --auto-approve

--output-format text|json|stream-json

text: 일반 텍스트 / json: 구조화된 데이터 / stream-json: 실시간 스트리밍
claude -p "분석" --output-format json main.py

claude --max-turns 5 -p "작업해줘"

효과매번 "이 프로젝트는 파이썬이고, 주석은 한국어로 써줘..." 라고 설명하지 않아도 돼요. 한번 적어두면 자동으로 기억해요.
팀작업팀원들이 모두 같은 CLAUDE.md를 쓰면 클로드가 일관된 방식으로 작업해줘요.

개념MCP 서버란 무엇인가?
▼
MCP (Model Context Protocol) 설명
쉬운설명클로드에게 "손과 발"을 달아주는 것이에요. 기본 클로드는 대화만 할 수 있지만, MCP를 연결하면 실제 외부 시스템에 접근할 수 있어요.
예시파일시스템 MCP → 내 PC 파일 읽기/쓰기, GitHub MCP → 코드 저장소 관리, DB MCP → 데이터베이스 쿼리 실행
  • 📁
    파일시스템 — 지정된 폴더 파일 접근 권한 확장
  • 🐙
    GitHub — PR 생성, 코드 리뷰, 이슈 관리
  • 🗄️
    SQLite/DB — 데이터베이스에 직접 쿼리
  • 🔍
    Brave Search — 인터넷 검색 기능 추가
  • 📝
    Notion/Slack — 협업 도구 연동

▼

실전자주 쓰는 MCP 서버 연결 예시
▼
파일시스템 MCP — 내 폴더 접근 권한
$claude mcp add filesystem -- npx -y @modelcontextprotocol/server-filesystem /내폴더경로
GitHub MCP — 저장소 관리
$claude mcp add github -- npx -y @modelcontextprotocol/server-github
SQLite MCP — 데이터베이스 연결
$claude mcp add sqlite -- npx -y @modelcontextprotocol/server-sqlite 내데이터베이스.db

$claude mcp add brave-search -- npx -y @modelcontextprotocol/server-brave-search
MCP 서버는 npx로 자동 설치돼요. 인터넷 연결만 있으면 돼요!

▼
매번 명령어로 추가하기 귀찮으면, 설정 파일에 저장해두면 자동으로 불러와요.

전송방식MCP 전송 방식 & 원격 서버
▼
MCP 전송 방식 종류
stdio표준 입출력 방식 (기본값). 로컬 프로세스로 실행. 가장 일반적.
streamableHttpHTTP 스트리밍 방식. 원격 MCP 서버 연결 시 권장 (신규).
sseServer-Sent Events 방식. 레거시. 새 서버는 streamableHttp 사용 권장.

$claude mcp add --transport streamableHttp myserver https://서버주소/mcp

$claude --mcp-config ./my-mcp.json
📄 my-mcp.json — streamableHttp 서버 설정 예시
{ "mcpServers": { "remote-server": { "transport": "streamableHttp", "url": "https://my-mcp-server.com/mcp", "headers": { "Authorization": "Bearer 토큰값" } } } }
OAuth 인증도 지원돼요! claude mcp add --oauth 로 OAuth 흐름으로 인증할 수 있어요.

멀티에이전트 & 서브에이전트

개념에이전트 모드란?
▼
에이전트 vs 일반 대화의 차이
일반대화내가 묻고 → 클로드가 답하고 → 내가 다음 질문. 한 번에 하나씩.
에이전트내가 목표를 주면 → 클로드가 스스로 계획 → 여러 단계를 자동으로 순서대로 실행. 나는 결과만 확인!
비유일반: 직접 요리 → 에이전트: 요리사에게 "오늘 저녁 준비해줘" 하고 맡기는 것
  • 🧠
    오케스트레이터 — 전체 작업을 계획하고 서브에이전트들에게 지시
  • ⚙️
    서브에이전트 — 실제로 파일 수정, 명령 실행, 테스트 등을 담당
  • 🔄
    복잡한 작업을 병렬로 처리해서 빠르게 완료 가능
실행에이전트 모드 실행 방법
▼
복잡한 작업을 에이전트에게 통째로 맡기기
$claude -p "프로젝트 전체 분석하고 버그 모두 수정해줘" --auto-approve
최대 실행 횟수 제한으로 안전하게
$claude --max-turns 10 -p "리팩토링해줘"
max-turns를 설정하면 최대 10번만 작업하고 멈춰요. 무한루프 방지!
대화형 에이전트 (중간중간 확인 가능)
$claude
일반 대화형으로 시작해도 "모든 파이썬 파일 분석해줘" 같은 큰 작업을 주면 에이전트처럼 동작해요.
에이전트가 실행 중일 때도 Ctrl+C 로 언제든 멈출 수 있어요!
서브에이전트서브에이전트 — 병렬 AI 작업 실행
▼

백그라운드가 기본서브에이전트는 이제 기본적으로 백그라운드에서 돌아요. 그래서 클로드가 결과를 기다리지 않고 계속 다른 일을 해요
권한 질문 전달백그라운드 서브에이전트가 권한이 필요하면 메인 세션에 질문이 떠요. 예전엔 조용히 거부됐는데 이제 물어봐요
중첩 가능서브에이전트가 자기 서브에이전트를 또 만들 수 있어요. 백그라운드 체인은 최대 5단계까지

모델 지정에이전트를 부를 때마다 model을 지정할 수 있어요. 안 하면 조용히 부모 모델을 상속하니 주의

Git 완전 정리

코드 버전 관리 핵심 명령어

핵심흐름매일 쓰는 Git 기본 흐름 (add → commit → push)
▼
Git 세 단계를 이해하자
add저장할 파일을 "바구니"에 담는 것. 아직 저장 안 됨.
commit바구니 안의 파일을 실제로 저장. "세이브 포인트" 만들기.
push내 PC의 저장 기록을 깃허브(클라우드)에 업로드.
1
상태 확인
$git status
어떤 파일이 변경됐는지, 새로 추가됐는지 확인
2
파일 추가 (스테이징)
$git add . ← 변경된 파일 전체
$git add 파일명.py ← 특정 파일만
3
커밋 (저장)
$git commit -m "작업 내용 메모"
메모는 나중에 볼 때 무슨 작업이었는지 알 수 있게 써요. 한국어도 OK!
4
푸시 (깃허브에 올리기)
